# Для родителя: настройка (один раз) и ревью (раз в неделю)

## Как это устроено

```
Ребёнок                       GitHub                         Вы
──────                        ──────                         ──
карта квестов (Pages)  ──►  читает PR и метки через API
делает квест в projects/
git push quest/w1-q4   ──►  Action: тесты + PR с отчётом ──► письмо/пуш «новый PR»
                                                             ревью, похвала, метки
                       ◄──  merge                       ◄── Approve + Merge
XP, уровень, бейдж и ваш отзыв появляются на карте
```

Ребёнку не нужен аккаунт GitHub (условия GitHub: аккаунт с 13 лет). Репозиторий принадлежит вам, а ребёнок
пушит через **deploy key** с правом записи. Pull request за неё открывает GitHub Action.

## Настройка (~1 час)

1. **Репозиторий.** Создайте на GitHub **публичный** пустой репозиторий, например `dev-quest`
   (без настоящей фамилии и личных данных в названии). Публичный — потому что тогда GitHub Pages бесплатен,
   а ребёнок без аккаунта может открыть ваши комментарии. Загрузите туда эти файлы.
2. **Actions.** Settings → Actions → General → *Workflow permissions*: «Read and write permissions» и галочка
   «Allow GitHub Actions to create and approve pull requests». Без этой галочки PR не будут создаваться.
3. **Pages.** Settings → Pages → *Deploy from a branch* → `master` / `(root)`. Через пару минут карта будет
   доступна по адресу `https://<ваш-логин>.github.io/dev-quest/`.
4. **Метки.** Actions → «Метки для ревью» → *Run workflow* (если не запустился сам при первой загрузке).
5. **Компьютер ребёнка.** Установите [VS Code](https://code.visualstudio.com/), [Git](https://git-scm.com/)
   и [Node.js LTS](https://nodejs.org/ru). На Windows в VS Code сделайте терминалом по умолчанию **Git Bash**
   (Ctrl+Shift+P → *Terminal: Select Default Profile*): команды в карточках написаны для bash.
6. **Ключ для push.** На компьютере ребёнка:
   ```bash
   ssh-keygen -t ed25519 -C "dev-quest"      # Enter, Enter, Enter
   cat ~/.ssh/id_ed25519.pub                 # скопировать
   ```
   Репозиторий → Settings → Deploy keys → *Add deploy key* → вставить, **галочка «Allow write access»**.
   Затем:
   ```bash
   git clone git@github.com:<ваш-логин>/dev-quest.git
   cd dev-quest
   git config user.name "Кира"
   git config user.email "kira@dev-quest.local"
   ```
7. **Аккаунты курсов** на вашу почту: [HTML Academy](https://htmlacademy.ru/) и [Code Basics](https://code-basics.com/ru).
   Хекслет понадобится только в мире 5.
8. **Закладка.** Сделайте карту квестов стартовой страницей браузера ребёнка.
9. **Проверка.** Пусть ребёнок пройдёт квест `w0-q2` при вас: после `git push` через минуту должен появиться PR.

## Ревью (5–10 минут на квест, примерно раз в неделю)

PR приходит с отчётом ребёнка и результатом автотестов. Внизу PR — свёрнутый чеклист. Коротко:

1. Работает ли? Видно ли понимание в отчёте?
2. **Одна конкретная похвала за действие** («нашла причину через Network»), а не за ум.
3. Максимум 1–2 улучшения.
4. Метки: `xp+25` / `xp+50` / `xp+100` за доп. испытания, `badge:*` за то, *как* она работала.
5. **Approve + Merge** — квест засчитан. Или **Request changes** — она доработает в той же ветке.

Ваш комментарий появится на карте под заголовком «Отзывы». Это главный источник похвалы, поэтому пишите его ей, а не себе.

Метка `нужна-помощь` на PR значит, что в отчёте есть раздел «Вопрос».

## Необязательно, но сильно помогает

- **5-минутное демо раз в неделю:** она показывает, что сделала. Для ребёнка, которого мотивирует похвала, это сильнее любых XP.
- **Награда за уровень или за босса:** договоритесь заранее, что получает за каждого побеждённого босса.
- **Ретро после мира 1** (≈ 6 недель): хочет ли продолжать, что раздражает, нужен ли платный HTML Academy.

## Когда ей исполнится 13

Она создаёт свой аккаунт GitHub. Переведите репозиторий на неё (Settings → Transfer) или добавьте её
как collaborator. Тогда она будет открывать PR сама, а deploy key можно удалить.

## Как менять план

Все квесты — в `hub/quests.js`: тексты, ссылки, XP, порядок. Карта перестраивается сама.
Ручная отметка квеста без PR — `hub/progress.js`.
