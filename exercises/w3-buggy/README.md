# 🐞 Охота на баги

В `buggy.js` пять функций, и в каждой спрятан баг.

1. Скопируй папку в `projects/w3-q9/`, запусти `node --test` — увидишь 5 красных тестов.
2. Читай сообщение каждого теста: `expected` — что ожидалось, `actual` — что получилось.
3. Найди баг. Попробуй хотя бы один найти отладчиком: в WebStorm кликни слева от номера строки
   (появится красная точка — breakpoint), потом правый клик по `buggy.test.js` → **Debug 'buggy.test.js'**.
   Выполнение остановится на точке: внизу видно значения переменных, а F8 делает шаг дальше.
4. Почини. Файл с тестами не меняй.

В отчёте для каждого бага: в чём была ошибка и как ты её вычислил(а).
