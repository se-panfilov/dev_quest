# 👹 Босс: «Зал героев» по макету

Так работают настоящие верстальщики: дизайнер присылает картинку, а ты делаешь из неё страницу.

- `desktop.png` — как страница выглядит на компьютере (ширина 1280px).
- `mobile.png` — как она выглядит на телефоне (ширина 375px).

## Подсказки дизайнера

| Что | Значение |
|---|---|
| Фон страницы | `#101426` |
| Фон шапки | `#181d36`, снизу полоса 3px `#ffd84d` |
| Фон карточки | `#1b2140`, рамка 2px `#2a3260`, скругление 20px |
| Жёлтый (кнопки, логотип) | `#ffd84d`, текст на нём `#1a1400` |
| Серый текст | `#9aa1c7` |
| Полоски навыков | сила `#ff6b6b`, магия `#7aa2ff`, ловкость `#4de08a` |
| Цвета кружков-аватаров | `#6c4bd8`, `#c0573a`, `#2f9e6b`, `#d8862f`, `#4a5a8a`, `#c74b9a` |
| Аватары | эмодзи 🧙 🛡️ 🏹 🐉 🗡️ ✨ (можно свои картинки) |

Точные размеры и отступы подбери на глаз — «пиксель в пиксель» не нужно.
Подсказка: сравнивай свою страницу и макет рядом, переключаясь между вкладками.

Фильтры («Все», «Воины»…) и кнопки пока просто для красоты — оживлять их будем в мире 4.
