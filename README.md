# 🗺️ Dev Quest — путь в веб-разработку

Это игра, в которой прокачивается не персонаж, а ты. 9 миров, в каждом — квесты и босс.
За каждую принятую работу — XP, уровни, звания и бейджи. В конце пути ты делаешь настоящие сайты
и приложения со своим сервером. Без «волшебных» конструкторов и без ИИ, который всё делает за тебя
(он откроется позже — как суперспособность, которую надо заслужить).

Займёт это примерно 2–3 года. Звучит долго. Но каждый квест — около недели, каждый босс — пара недель,
а прогресс видно на карте сразу. Как в любой нормальной RPG.

## С чего начать

1. Открой **карту квестов**: `https://<твой-логин>.github.io/dev_quest/`. Пока ты там безымянный NPC.
2. Нажми **«Следующий шаг»**. Первый квест — **«Создание персонажа»**: ты впишешь своё имя
   в `hub/config.js` и отправишь первый pull request. После его принятия карта узнает, кто ты.
3. Дальше всё так же: карточка квеста → работа в `projects/` → `git push` → проверка → XP.

## Что где лежит

| Папка | Что там |
|---|---|
| `projects/` | **Твои работы.** Одна папка на квест: `projects/w1-q4/` и так далее |
| `exercises/` | Готовые задания: сломанные страницы, задачи с автотестами, макеты. Их копируешь в `projects/` |
| `hub/` | Сама карта квестов. Трогать не нужно (кроме `config.js` в первом квесте) |

## Правила

- **Одна ветка — один квест:** `quest/w1-q4`. Pull request откроется сам после `git push`.
- **В каждой папке квеста — `README.md`** с отчётом: что сделано, что бесило, что понято.
  Есть вопрос — добавь в отчёт раздел `## Вопрос`, ревьюер увидит.
- **Застрял(а) на 15 минут** — карта → «Шпаргалки → Застрял?».
- **ИИ открывается по уровням.** Раньше времени — это чит, и на боссе он аукнется.
