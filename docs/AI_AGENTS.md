# Настройка ИИ-агентов

Документ для ментора и автора шаблона (на русском, это документация, а не инструкция для агента). Агенты его не загружают каждый раз: в [AGENTS.md](../AGENTS.md) на него есть ссылка.
Правила для агентов — в AGENTS.md, подробный порядок работы — в skills. Инструкции для агентов написаны на английском: так их точнее понимают агенты и они короче в токенах. Общаются агенты с учеником и ментором на русском. Это инструкции, а не ограничения доступа и не песочница.
Что агент реально сделает, зависит от хоста, его версии, настроек и прав, которые ему выдали.

Основа взята из [se-panfilov/modern_monorepo_template](https://github.com/se-panfilov/modern_monorepo_template) и уменьшена под учебный репозиторий.

## Файлы и как их находят хосты

| Хост | Правила | Skills |
| --- | --- | --- |
| Claude Code | `CLAUDE.md` импортирует AGENTS.md (`@AGENTS.md`) | Адаптеры в `.claude/skills/<name>/SKILL.md` ведут к общим файлам. Вызов: `/<name>` |
| Codex | Читает AGENTS.md | Находит skills в `.agents/skills/`. Вызов: `$<name>` |
| Cursor | Читает AGENTS.md | Находит skills в `.agents/skills/`, если хост это поддерживает. Иначе — по ссылкам из AGENTS.md |
| GitHub Copilot | `.github/copilot-instructions.md` ведёт к AGENTS.md | По ссылкам из AGENTS.md |
| Gemini CLI | `GEMINI.md` импортирует AGENTS.md | По ссылкам из AGENTS.md |
| JetBrains Junie (WebStorm) | Читает AGENTS.md | По ссылкам из AGENTS.md |

Адаптеры в `.claude/skills/` — обычные файлы, а не символические ссылки: так всё работает и на Windows без режима разработчика.
Описание (`description`) в адаптере совпадает с описанием в общем файле. Меняешь одно — меняй и другое.

**Допущение.** Чтение AGENTS.md в Junie и поддержка `.agents/skills/` в Cursor, Copilot и Junie зависят от версии хоста. Проверь по разделу «Проверка сессии».

У каждого третьестороннего skill есть `LICENSE` и `UPSTREAM.md` с источником и ревизией.

### Изменения относительно оригинала

Тексты третьесторонних skills скопированы из modern_monorepo_template вместе с его адаптациями.
Раздел «Project integration» в каждом skill переписан под этот репозиторий:

- агент общается и пишет отчёты на русском, по [правилам письма](WRITING.md); сами инструкции — на английском;
- skill сначала проверяет уровень ИИ ученика и не повышает его;
- find-bugs: в режиме 🤖 ИИ-объяснителя не даёт готовое исправление, только место и наводящий вопрос. Добавлены пункты про DOM, сервер, SQL и тесты упражнений;
- code-simplifier: переписан под JavaScript, TypeScript и Vue. На низких уровнях не правит код, а предлагает одно место;
- grilling: вопросы на русском, для ученика — про планы квестов и проектов, без готового кода;
- doc-coauthoring: не применяется к отчёту квеста, его ученик пишет сам;
- gha-security-review: учитывает, что `quest.yml` работает внутри форка. Отклонения от правил AGENTS.md — отдельным разделом;
- agents-md и writing-for-agents: импорт в `CLAUDE.md` вместо символической ссылки.

### Что не взято

| Skill | Почему |
| --- | --- |
| second-opinion | Отправляет код и правила во внешние ИИ-сервисы. Для репозитория ученика это лишний риск |
| supply-chain-risk-auditor, skill-scanner | Запускают скрипты и сетевые запросы. Зависимостей в шаблоне нет |
| sharp-edges, differential-review, fp-check | Глубокий аудит безопасности библиотек. Для учебного репозитория избыточен |
| property-based-testing | Нужна библиотека генерации данных. В курсе её нет |
| project-workflow, new-package | Описывают монорепо: пакеты, `dist/`, версии. Заменены на template-workflow и code-standards |

Если позже понадобится какой-то из них, перенеси его из modern_monorepo_template вместе с `LICENSE` и `UPSTREAM.md`
и перепиши раздел «Project integration». Это решение человека: см. «Безопасность» в AGENTS.md.

## Проверка сессии

1. Открой новую сессию агента в репозитории.
2. Спроси, какие файлы правил и какие skills он загрузил. Ничего не меняй.
3. Проверь, что агент знает уровни ИИ ученика, запреты и язык общения.
4. Проверь, что skill из таблицы открывает общий файл в `.agents/skills/`.

В Claude Code загруженные правила показывает `/context`, в Gemini CLI — `/memory show`.
Если хост не загрузил правила сам, приложи AGENTS.md к первому сообщению.

## Сопровождение

- Правила меняй в AGENTS.md, порядок работы — в общем skill. Адаптеры держи короткими.
- Не добавляй в адаптеры права, хуки, команды и сетевые действия.
- Не добавляй файлы настроек хостов (`.claude/settings.json`, `.mcp.json` и другие из AGENTS.md) без решения человека.
