# 🎒 Инвентарь героя

Напиши функции для инвентаря в `inventory.js`. Описание каждой — в комментарии над ней.

1. Скопируй папку в `projects/w3-q8/`.
2. `cd projects/w3-q8` → `node --test`.
3. Добейся, чтобы все 7 тестов стали зелёными.

Полезные методы массивов: `filter`, `reduce`, `find`, `findIndex`, `slice`, `sort`, оператор `...`.
Подсказка к 7-му: `sort` меняет исходный массив, поэтому сначала сделай копию.
