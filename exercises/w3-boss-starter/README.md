# 👹 Босс: Викторина

Интерфейс уже готов (`ui.js`, `index.html`, `style.css`). Твоя задача — **мозг игры**.

1. Скопируй папку в `projects/w3-boss/`.
2. Напиши функции в `game.js` (описание каждой — в комментариях).
3. Напиши 10 своих вопросов в `questions.js`.
4. Запусти `node --test` — добейся, чтобы всё было зелёным.
5. Открой `index.html` в WebStorm и нажми иконку браузера в правом верхнем углу редактора — сыграй!

Пока функции не написаны, страница в браузере будет пустой или с ошибкой в консоли (F12) — это нормально.

**Доп. испытания (+XP):** перемешивание вопросов, таймер на ответ, серия из 3 правильных ответов подряд даёт x2 очков,
свой дизайн в `style.css`.
