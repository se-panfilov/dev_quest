# 🔍 Детектив DevTools

Страница «Профиль героя» сломана. На ней **6 багов**. Твоя задача — найти причину каждого
с помощью инструментов разработчика (F12) и починить.

## Как должно быть

1. Видна картинка-портрет героя.
2. Заголовок «Кибер-рыцарь» крупный и жёлтый.
3. «Уровень 12» серо-голубой, крупный и жирный.
4. Секретный приём можно прочитать.
5. На телефоне (ширина 375px, режим устройства в DevTools) нет горизонтальной прокрутки.
6. Внизу есть жёлтая кнопка «Вступить в гильдию».

## Подсказки детектива

- **Elements** — выбери элемент стрелкой и посмотри, какие стили к нему применились. Зачёркнутые
  или подсвеченные жёлтым треугольником свойства — подозрительные.
- **Console** и **Network** — покажут файлы, которые не загрузились (красным).
- В Elements можно менять CSS прямо в браузере, чтобы проверить догадку. Потом перенеси исправление в файл.
